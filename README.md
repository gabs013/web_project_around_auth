# Aplicación Web Interactiva "Around" — TripleTen Bootcamp | 2026

## Descripción:

Desarrollo de una aplicación web interactiva inspirada en una plataforma para compartir fotografías, que permite a los usuarios gestionar una galería visual, editar su perfil y visualizar imágenes mediante una interfaz dinámica y responsiva.

El proyecto fue desarrollado con React y se conecta con las API de Around para gestionar la autenticación, la información del usuario y las tarjetas.

## Tecnologías:

React
React Router
Vite
JavaScript (ES6+)
JSX
HTML5
CSS3
Metodología BEM
API REST
JWT y `localStorage`
ESLint
Git y GitHub

## Logro:

 En este proyecto migré una aplicación desarrollada originalmente con JavaScript vanilla a React. Organicé la interfaz en componentes reutilizables, incorporé el consumo de API, implementé autenticación mediante JWT y protegí el contenido privado mediante React Router.

 También desarrollé una interfaz responsiva para adaptar la navegación, los formularios y las ventanas modales a distintos tamaños de pantalla.

## Funcionalidades:

 Registro de nuevos usuarios.
 Inicio y cierre de sesión.
 Autenticación mediante JWT.
 Persistencia de la sesión mediante `localStorage`.
 Protección de rutas privadas.
 Mensajes de confirmación y error durante el registro.
 Visualización del correo electrónico del usuario.
 Edición del nombre, descripción y avatar del perfil.
 Visualización de una galería de imágenes.
 Apertura de imágenes en ventanas emergentes.
 Edición del perfil y del avatar.
 Agregado y eliminación de tarjetas.
 Marcado y desmarcado de tarjetas con “Me gusta”.
 Menú móvil para consultar la sesión y cerrar sesión.
 Diseño responsivo.
